# Audio Player Site

Audio player at `/palakodi/` (plain HTML/CSS/JS). Replace `palakodi/assets/song.mp3` to change the song.

## Run locally
    python3 -m http.server 8000   # open http://localhost:8000

## Host free on open-source-friendly platforms
- **GitHub Pages**: push this folder to a repo → Settings → Pages → deploy from `main` / root.
- **Codeberg Pages / GitLab Pages / Netlify / Cloudflare Pages**: upload the folder as-is.

Keyboard: Space = play/pause, ←/→ = ±5s, L = loop.
